# Credit Scoring: разработка и валидация

🇬🇧 [English](README.md) · 🇷🇺 Русский

Построение и сравнение моделей кредитного скоринга (PD) на данных **Lending Club 2007–2018**:

- **Логистическая регрессия на WoE**: интерпретируемая базовая модель (скоркарта)
- **LightGBM**: challenger
- **CatBoost**: challenger

Итог: сравнение моделей по качеству, стабильности и калибровке плюс отчёт о валидации.

## Постановка задачи

**Цель:** оценить вероятность дефолта (PD) заёмщика на момент выдачи займа
и сравнить три подхода по качеству, стабильности, калибровке и интерпретируемости.

| Параметр | Решение |
|---|---|
| Объект | Займ Lending Club, срок **36 месяцев** |
| Момент прогноза | Дата выдачи (`issue_d`) |
| Горизонт | **12 месяцев** с даты выдачи (годовой PD, как в Basel / CRR) |
| Таргет | `1`: займ вышел на просрочку **90+ дней в первые 12 месяцев** (определение дефолта CRR Art. 178)<br>`0`: всё остальное, включая ещё открытые займы и дефолты после 12-го месяца |
| Выборка | Займы на 36 мес., выданные 2010–2017, индивидуальные заявки, с полными 12 месяцами наблюдения |
| Признаки | Только известные на момент выдачи: анкета, кредитная история, условия займа |
| Основная метрика | **Gini** на OOT |
| Доп. метрики | KS, PSI, калибровка (биномиальный тест), падение Gini train → OOT |

### Почему таргет на 12 месяцев
Данные выгружены в марте 2019 года. Среди займов 2016 года 27 % ещё открыты,
2017 года — 58 %. Таргет «чем закончился займ» (lifetime) известен только для
закрытых займов, а если их выбросить, в поздних годах останутся в основном рано
закрытые займы, и доля дефолтов будет смещена. С таким таргетом выборку пришлось
бы обрезать на 2015 году.

Таргет «дефолт в первые 12 месяцев» известен для каждого займа старше 12 месяцев,
в том числе для открытых. Это и стандарт в банках: регуляторный PD считается
на горизонте одного года.

| Год выдачи (36 мес.) | Займов | Открытых | DR за весь срок (закрытые) | DR за 12 мес. |
|---|---|---|---|---|
| 2010 | 9 156 | 0 % | 10,9 % | 3,5 % |
| 2011 | 14 101 | 0 % | 10,6 % | 3,1 % |
| 2012 | 43 470 | 0 % | 13,6 % | 3,7 % |
| 2013 | 100 422 | 0 % | 12,3 % | 2,9 % |
| 2014 | 162 570 | 0 % | 13,7 % | 2,9 % |
| 2015 | 283 173 | 0 % | 14,9 % | 3,6 % |
| 2016 | 323 495 | 27 % | 20,8 % (смещено) | 4,4 % |
| 2017 | 320 419 | 58 % | 23,1 % (смещено) | 4,1 % |

### Как восстанавливается таргет
В публичных данных нет помесячной истории платежей, только текущий статус и
накопленные суммы. Поэтому месяц дефолта восстанавливается по числу оплаченных платежей:

```
months_paid   = floor((total_rec_prncp + total_rec_int) / installment)
default_month = months_paid + 1 + 3     # первый пропущенный платёж + 90 дней
target        = 1, если статус дефолтный и default_month <= 12
```

Проверка на «созревших» займах 2010–2014: флаг совпадает с независимым расчётом
по дате последнего платежа у **96,3 %** дефолтных займов. Займ попадает в выборку,
если `issue_d + 12 мес. + 3 мес. запаса` не позже даты среза (март 2019).
Столбцы, из которых строится таргет, перечислены в `TARGET_ONLY_COLS` и никогда
не становятся признаками: перед обучением это проверяет `assert_no_leakage`.

### Ограничения таргета
- Таргет **восстановлен**, а не наблюдён: просрочки, которые потом были погашены,
  не видны; частичное досрочное погашение перед дефолтом сдвигает месяц дефолта позже.
  Оба эффекта немного занижают DR.
- Debt settlement (до 2,5 % займов 2016 года) делает график платежей нерегулярным;
  в части 2 будет проверка чувствительности без них.
- Совместные заявки (7,5 % займов 2017 года) исключены: их поля есть только с конца 2015 года.

### Критерии успеха
- Gini логистической регрессии на OOT **выше бенчмарка**: подкласса Lending Club (`sub_grade`) на тех же займах OOT (Gini ≈ 0,40); бустинги должны дать прирост, оправдывающий потерю интерпретируемости
- Падение Gini train → OOT ≤ 5 п.п. (относительно ≤ 10 %)
- PSI скора train → OOT < 0,1 (стабильно), 0,1–0,25 — допустимо с обоснованием
- Знаки и монотонность WoE в логистической регрессии согласуются с бизнес-логикой

## Данные

Источник: Kaggle, датасет *Lending Club* (wordsforthewise), файл `accepted_2007_to_2018Q4.csv`
(2,26 млн займов, 151 столбец). Положить в `data/raw/`. Данные в git не коммитятся.

**Важно — утечки:** используются только признаки, известные на момент выдачи займа
(никаких `total_pymnt`, `recoveries`, `last_pymnt_d`, `out_prncp`, `last_fico_range_*` и т.п.).

### Разбиение
- **OOT**: займы 2017 года (~296 тыс. индивидуальных), самый свежий год с 12 месяцами наблюдения
- **Окно обучения выбирается экспериментом**, а не задаётся заранее. Часть бюро-полей
  появилась только во 2–4 кв. 2012, ещё 14 — в 1 кв. 2016, поэтому длинное окно даёт
  больше истории, а короткое — больше признаков. Кандидаты: 1 пол. 2016; 2015 – 1 пол. 2016;
  2013 – 1 пол. 2016, каждое с новыми полями 2016 года и без них. Окна сравниваются
  на отдельном срезе (2 пол. 2016), а не на OOT, чтобы OOT оставался честной проверкой.
- **Результат:** побеждает самое длинное окно со всеми полями (Gini на срезе 0,402
  против 0,377–0,399), причём в каждом месяце среза; Gini растёт с длиной окна.
  Окно длиной 42 месяца сдвинуто так, чтобы заканчиваться в декабре 2016:

| Выборка | Выдача | Займов | DR |
|---|---|---|---|
| Train | 2013-07 … 2016-12 | 658 463 | 3,70 % |
| Test (случайные 20 %) | 2013-07 … 2016-12 | 164 616 | 3,70 % |
| OOT | 2017-01 … 2017-12 | 296 484 | 4,04 % |
- Займы 2007–2009 годов не используются: их мало, и они выданы в кризис

### Отбор признаков (скоркарта)
Оптимальный биннинг на train (в интервале ≥ 5 % займов, монотонный тренд риска,
пропуски — отдельный интервал), затем задокументированная воронка: IV < 0,02 →
стабильность (PSI и порядок риска по интервалам) → корреляция > 0,7 → VIF > 5.
Отобрано **25 из 78 признаков**; решение и причина по каждому кандидату — в
`reports/tables/03_feature_selection.csv`. 14 бюро-полей, которые есть только с 2016 года,
бинируются на займах 2016 года, а более старым займам ставится нейтральный WoE,
чтобы пропуск не кодировал период выдачи.

### Модели (выборка test, до OOT)
| Модель | Gini test |
|---|---|
| Скоркарта: логистическая регрессия на WoE, 21 признак | 0,356 |
| LightGBM / LightGBM монотонная | 0,443 / 0,443 |
| CatBoost / CatBoost монотонная | 0,438 / 0,438 |
| Бенчмарк: подкласс Lending Club | 0,417 |

Бустинги обходят собственный грейд кредитора, скоркарта — нет: грейд построен на данных,
которых нет в публичном датасете. Монотонные ограничения не стоят точности. При этом
каждая модель **добавляет** информацию к грейду: вместе с ним LightGBM поднимает Gini
с 0,417 до 0,472, скоркарта — до 0,435. Итоговый вердикт — на OOT (2017) в части 2.

### Метрики валидации
- **Дискриминация:** Gini, KS (train / test / OOT), падение Gini
- **Стабильность:** PSI скора и признаков, Gini по кварталам
- **Калибровка:** предсказанный vs фактический DR по бакетам, биномиальный тест, Hosmer–Lemeshow
- **Интерпретируемость:** коэффициенты и монотонность WoE (LogReg), SHAP (бустинги)
